# Tugas UAS Mandiri - Spring Framework

## 1. Topik Pilihan: Spring Boot
Berikut adalah penjabaran analisis menggunakan metode 5W untuk topik **Spring Boot**:

* **What (Apa itu Spring Boot?):** 
  Spring Boot adalah sub-proyek dari Spring Framework yang dirancang untuk mempercepat proses pembuatan dan konfigurasi aplikasi berbasis Java (terutama berbasis web atau microservices) secara mandiri (*standalone*) tanpa perlu repot mengatur file XML atau konfigurasi server yang rumit.

* **Why (Mengapa menggunakan Spring Boot?):** 
  Karena Spring Boot menyediakan fitur *Auto-Configuration* (pengaturan otomatis), memiliki server bawaan (seperti Tomcat), serta dilengkapi manajemen *dependencies* yang praktis melalui Maven atau Gradle sehingga developer bisa fokus langsung ke logika program.

* **When (Kapan teknologi ini digunakan?):** 
  Digunakan ketika kita ingin membangun sistem backend, RESTful API, atau aplikasi skala menengah hingga besar yang membutuhkan pengembangan yang cepat, efisien, dan siap produksi (*production-ready*).

* **Who (Siapa yang menggunakan & mengembangkan?):** 
  * **Pengembang:** Digunakan secara luas oleh para *Java Developer*, perusahaan startup, hingga perusahaan besar (Enterprise).
  * **Pencipta:** Dikembangkan dan dipelihara oleh tim di bawah naungan VMware (sebelumnya Pivotal).

* **Where (Dimana biasanya diterapkan?):** 
  Diterapkan di lingkungan *Cloud Server* (seperti AWS, Google Cloud, Azure), arsitektur berbasis *Microservices*, atau sebagai layanan backend yang dihubungkan dengan frontend (seperti React, Vue, atau aplikasi mobile).
